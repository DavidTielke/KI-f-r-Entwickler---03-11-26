# Schließen mit Escape

## Meta
- **State:** Implemented

## User Story
Als Administration möchte ich offene Dialoge mit der Escape-Taste schließen, damit ich ohne Maus schnell ausbrechen kann.

## Description
Die Taste Escape schließt den Anlegen-/Bearbeiten-Dialog und den Lösch-Bestätigungsdialog der Haustiere-Seite.

## Akzeptanzkriterien
- Ein Drücken von Escape schließt den Anlegen-/Bearbeiten-Dialog der Haustiere-Seite.
- Ein Drücken von Escape schließt den Lösch-Bestätigungsdialog der Haustiere-Seite.
