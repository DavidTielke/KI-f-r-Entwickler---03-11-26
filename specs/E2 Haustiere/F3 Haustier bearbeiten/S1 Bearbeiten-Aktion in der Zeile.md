# Bearbeiten-Aktion in der Zeile

## Meta
- **State:** Implemented

## User Story
Als Administration möchte ich ein Haustier über seine Zeile direkt bearbeiten, damit ich Daten schnell aktualisieren kann.

## Description
Jede Zeile der Haustierliste enthält einen Icon-Button „Bearbeiten", der den Bearbeiten-Dialog für das zugehörige Haustier öffnet.

## Akzeptanzkriterien
- Jede Zeile der Liste enthält eine Bearbeiten-Aktion.
- Die Bearbeiten-Aktion ist ein Icon-Button.
- Die Bearbeiten-Aktion trägt das Accessibility-Label „Haustier {id} bearbeiten".
- Ein Klick auf die Bearbeiten-Aktion öffnet den Bearbeiten-Dialog für das Haustier (siehe F3 S2).
