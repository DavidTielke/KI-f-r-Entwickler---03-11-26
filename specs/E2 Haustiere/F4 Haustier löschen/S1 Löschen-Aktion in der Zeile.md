# Löschen-Aktion in der Zeile

## Meta
- **State:** Implemented

## User Story
Als Administration möchte ich ein Haustier über seine Zeile löschen, damit ich den Bestand pflegen kann.

## Description
Jede Zeile der Haustierliste enthält einen Icon-Button „Löschen" (Danger-Variante), der den Lösch-Bestätigungsdialog öffnet.

## Akzeptanzkriterien
- Jede Zeile der Liste enthält eine Löschen-Aktion.
- Die Löschen-Aktion ist ein Icon-Button in der Danger-Variante.
- Die Löschen-Aktion trägt das Accessibility-Label „Haustier {id} löschen".
- Ein Klick auf die Löschen-Aktion öffnet den Lösch-Bestätigungsdialog für das Haustier (siehe F4 S2).
