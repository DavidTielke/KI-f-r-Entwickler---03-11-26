# Bearbeiten-Aktion in der Zeile

## Meta
- **State:** Implemented

## User Story
Als Administration möchte ich eine Person über ihre Zeile direkt bearbeiten, damit ich Daten schnell aktualisieren kann.

## Description
Jede Zeile der Personenliste enthält einen Icon-Button „Bearbeiten", der den Bearbeiten-Dialog für die zugehörige Person öffnet.

## Akzeptanzkriterien
- Jede Zeile der Liste enthält eine Bearbeiten-Aktion.
- Die Bearbeiten-Aktion ist ein Icon-Button.
- Die Bearbeiten-Aktion trägt das Accessibility-Label „Person {id} bearbeiten".
- Ein Klick auf die Bearbeiten-Aktion öffnet den Bearbeiten-Dialog für die Person (siehe F4 S2).
