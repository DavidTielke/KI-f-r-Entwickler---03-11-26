# Schließen mit Backdrop-Klick

## Meta
- **State:** Implemented

## User Story
Als Administration möchte ich Dialoge per Klick auf den Hintergrund schließen, damit ich ohne die Schließen-Buttons ausbrechen kann.

## Description
Beide Dialogarten (Formular und Bestätigung) liegen auf einer dunklen Backdrop; ein Klick auf die Backdrop außerhalb des Dialogs schließt den Dialog.

## Akzeptanzkriterien
- Ein Klick auf die Backdrop außerhalb des Dialogs schließt den Anlegen-/Bearbeiten-Dialog.
- Ein Klick auf die Backdrop außerhalb des Dialogs schließt den Lösch-Bestätigungsdialog.
- Ein Klick innerhalb des Dialogs schließt den Dialog nicht.
