# Löschen-Aktion in der Zeile

## Meta
- **State:** Implemented

## User Story
Als Administration möchte ich eine Person über ihre Zeile löschen, damit ich den Bestand pflegen kann.

## Description
Jede Zeile der Personenliste enthält einen Icon-Button „Löschen" (Danger-Variante), der den Lösch-Bestätigungsdialog öffnet.

## Akzeptanzkriterien
- Jede Zeile der Liste enthält eine Löschen-Aktion.
- Die Löschen-Aktion ist ein Icon-Button in der Danger-Variante.
- Die Löschen-Aktion trägt das Accessibility-Label „Person {id} löschen".
- Ein Klick auf die Löschen-Aktion öffnet den Lösch-Bestätigungsdialog für die Person (siehe F5 S2).
