# Häufige Fragen zur ganzen Anwendung

Diese Seite beantwortet Fragen, die alle Module betreffen. Fragen zu einem einzelnen Modul stehen in dessen eigenen Fragen: [Personen](E1-personen/faq.md), [Haustiere](E2-haustiere/faq.md) und [Software Factory](E3-software-factory/faq.md).

### Wie öffne ich die Anwendung?
Die Personen- und Haustierverwaltung öffnen Sie im Browser unter `http://localhost:3000`. Die Software Factory öffnen Sie unter `http://localhost:4000`. Beide Adressen funktionieren nur auf dem Rechner, auf dem die Anwendung läuft.
Ausführlich: [Erste Schritte](00-erste-schritte.md)

### Muss ich mich anmelden?
Nein. Beide Teile öffnen sich ohne Anmeldung. Unten in der linken Leiste sehen Sie nur, auf wessen Namen gearbeitet wird.
Ausführlich: [Erste Schritte](00-erste-schritte.md)

### Wie wechsle ich zwischen den Seiten?
Klicken Sie in der linken Leiste auf den gewünschten Eintrag. Der gewählte Eintrag ist orange hinterlegt. So wissen Sie jederzeit, wo Sie sind.
Ausführlich: [Erste Schritte](00-erste-schritte.md)

### Wie komme ich von der Verwaltung zur Software Factory?
Die beiden Teile haben getrennte Adressen. Öffnen Sie im Browser einen neuen Tab und tippen Sie `http://localhost:4000` ein. Zurück zur Verwaltung geht es mit `http://localhost:3000`.
Ausführlich: [Erste Schritte](00-erste-schritte.md)

### Warum öffnet sich die Seite nicht?
Der Browser meldet dann, die Seite sei nicht erreichbar. Entweder ist die Adresse falsch geschrieben, oder der Teil läuft nicht. Prüfen Sie zuerst die Adresse. Läuft der Teil nicht, bitten Sie die Person, die die Anwendung betreut, ihn zu starten.
Ausführlich: [Erste Schritte](00-erste-schritte.md)

### Was bedeutet „Der Factory-Dienst ist nicht erreichbar.“?
Die Software Factory kann ihren Hintergrunddienst auf diesem Rechner nicht erreichen. Prüfen Sie, ob die Software Factory noch gestartet ist. Laden Sie die Seite danach neu.
Ausführlich: [Die Oberfläche der Software Factory](E3-software-factory/01-navigation.md)

### Wann sollte ich die Seite neu laden?
Die Verwaltung aktualisiert sich nach Ihren Änderungen selbst. Laden Sie die Seite neu, wenn eine Liste leer bleibt, alte Zahlen zeigt oder eine Fehlermeldung nicht verschwindet. Klicken Sie dazu im Browser auf das runde Pfeilsymbol neben der Adresszeile oder drücken Sie die Taste F5. Die Software Factory aktualisiert sich von selbst und braucht das nur bei unterbrochener Verbindung.
Ausführlich: [Die Personenliste](E1-personen/02-personenliste.md)

### Gehen meine Eingaben verloren, wenn ich die Seite neu lade?
Ein Fenster, das Sie nicht gespeichert haben, schließt sich beim Neuladen. Die Eingaben darin sind dann weg. Gespeicherte Personen und Haustiere bleiben erhalten. Klicken Sie deshalb vor dem Neuladen auf **Speichern** oder **Anlegen**.
Ausführlich: [Dialoge schließen](E2-haustiere/05-dialoge-schliessen.md)

### Wie schließe ich ein Fenster, ohne zu speichern?
Klicken Sie auf **Abbrechen**, drücken Sie die Taste Esc oder klicken Sie neben das Fenster. In allen Fällen wird nichts gespeichert.
Ausführlich: [Dialoge schließen](E2-haustiere/05-dialoge-schliessen.md)

### Wie drucke ich eine Seite?
Die Anwendung hat keine eigene Druckfunktion. Drücken Sie im Browser die Tasten Strg und P. Wählen Sie dort Ihren Drucker oder **Als PDF speichern**. Die Vorschau zeigt, was gedruckt wird.
Ausführlich: [Erste Schritte](00-erste-schritte.md)

### Welchen Browser soll ich verwenden?
Verwenden Sie einen aktuellen Chrome oder Edge. Dort funktionieren alle Seiten, auch die Spracheingabe der Software Factory. In anderen Browsern fehlt die Spracheingabe möglicherweise.
Ausführlich: [Mit der Stimme arbeiten](E3-software-factory/05-sprache.md)

### Können mehrere Personen gleichzeitig arbeiten?
Sie können die Seiten in mehreren Tabs öffnen. Änderungen aus einem Tab sehen Sie in einem anderen Tab nach dem Neuladen. Löscht jemand einen Eintrag, den Sie gerade bearbeiten, meldet die Anwendung beim Speichern einen Fehler. Laden Sie dann die Seite neu und prüfen Sie die Liste.
Ausführlich: [Eine Person bearbeiten](E1-personen/04-person-bearbeiten.md)
